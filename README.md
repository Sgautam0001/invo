# Invo

Invo is a web-based invoice generator built with Next.js (App Router), TypeScript, and Shadcn UI.  
Create invoices, preview in real time, download as PDF, and optionally email the PDF.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS + Shadcn UI
- React Hook Form + Zod
- Puppeteer (PDF generation)
- Nodemailer (email sending)

## Features

- Create invoices using a simple form
- Live preview while editing
- Multiple invoice templates
- Save invoices in browser storage
- Export invoice data (JSON, XLSX, CSV, XML)
- Download invoice as PDF
- Send invoice PDF via email (optional)
